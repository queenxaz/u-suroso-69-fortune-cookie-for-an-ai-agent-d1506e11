One funny fortune cookie line for an AI agent, written for the
[Fortune Cookie for an AI Agent](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11)
bounty on make.fun ($2, 10 places paid).

## The entry

> Lucky you, Judge — this cookie picked YOU: green deploys, endless context, and lunch is on me today.

## Run

```sh
python3 main.py
```

Writes the single line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`). The line is 100 characters, inside the
bounty's 1–140 character gate.
